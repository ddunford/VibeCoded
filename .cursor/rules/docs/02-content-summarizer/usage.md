# Content Summarizer Usage Guide

## Getting Started

1. Launch the application
2. Choose input method:
   - URL input
   - PDF upload
   - Text input

## Basic Usage

### URL Summarization
1. Enter URL in the input field
2. Select summary length
3. Click "Generate Summary"
4. View results

### PDF Processing
1. Drag and drop PDF file
2. Select pages to process
3. Choose summary type
4. Generate summary

## Advanced Features

### Summary Customization
- Length options:
  - Brief
  - Detailed
  - Custom length
- Format options:
  - Bullet points
  - Paragraph
  - Key points

### Batch Processing
1. Upload multiple files
2. Set processing order
3. Configure output format
4. Process in batch

## Best Practices

1. URL Processing
   - Ensure URL is accessible
   - Check for paywalls
   - Verify content length

2. PDF Handling
   - Optimize file size
   - Check PDF quality
   - Consider page limits

3. Performance Tips
   - Use shorter summaries for quick results
   - Process large documents in chunks
   - Save frequently used settings
