# Content Summarizer Usage Guide

## Overview
Content Summarizer helps you extract and summarize content from web pages and PDF documents. This guide covers all features and best practices for getting optimal results.

## Features

### 1. URL Processing
Process any web page and get a concise summary:

Example:
```
Input: https://example.com/article
Output: 
- Main points extraction
- Key concepts highlighted
- Source attribution
```

### 2. PDF Processing
Extract and summarize content from PDF documents:

- Supported formats: PDF
- Maximum file size: 10MB
- Text extraction with formatting preservation

## Using the Interface

### URL Summarization
1. **Enter URL**:
   - Paste URL in the input field
   - Ensure URL is publicly accessible
   - Wait for validation

2. **Process Content**:
   - Click "Summarize"
   - View progress indicator
   - Review generated summary

### PDF Processing
1. **Upload File**:
   - Drag and drop PDF
   - Click upload area to browse
   - File validation occurs automatically

2. **View Results**:
   - Summary appears in main panel
   - Key points highlighted
   - Source information preserved

## Best Practices

### URL Processing
1. **URL Selection**:
   - Use direct article links
   - Avoid login-protected content
   - Check URL accessibility

2. **Content Types**:
   - Articles and blog posts
   - Documentation pages
   - News content
   - Research papers

3. **Optimal Results**:
   - Clean URLs without tracking parameters
   - Public content
   - Text-rich pages

### PDF Handling
1. **File Preparation**:
   - Ensure PDF is text-based (not scanned)
   - Keep file size under 10MB
   - Check PDF quality

2. **Processing Tips**:
   - Single document at a time
   - Allow full processing
   - Review extracted text

## Error Handling

### Common Issues
1. **URL Errors**:
   ```
   Error: Could not access URL
   ```
   - Check URL accessibility
   - Verify no login required
   - Try different browser

2. **PDF Errors**:
   ```
   Error: Could not process PDF
   ```
   - Verify file is not corrupted
   - Check file size
   - Ensure text is extractable

3. **Processing Errors**:
   ```
   Error: Timeout
   ```
   - Try again later
   - Check internet connection
   - Reduce content size

## Keyboard Shortcuts

| Action | Windows/Linux | Mac |

## Tips for Better Results

### URL Processing
- Use original source URLs
- Avoid redirects
- Wait for complete loading

### PDF Processing
- Use searchable PDFs
- Optimize file size
- Check formatting

### General Tips
- One input at a time
- Review summaries
- Save important results
- Use appropriate content

## Limitations

### URL Processing
- No login-protected content
- Public URLs only
- Standard HTTP/HTTPS only

### PDF Processing
- 10MB file size limit
- Text-based PDFs only
- Single file processing
